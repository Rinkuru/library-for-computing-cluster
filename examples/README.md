## Примеры

Здесь лежат программы `integral_master` и `integral_worker`.
Они показывают, как использовать библиотеку для вычисления интеграла.
Master создаёт задачи и раздаёт их worker-ам.
Worker получает задачу, считает её в потоках и отправляет результат.
Обычный запуск тестов выполняется через `make test` из корня проекта.
Сценарии запуска лежат в папке `scripts`.
Пример работает на одной машине через localhost.
