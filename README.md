## Библиотека для вычислительного кластера

Учебный проект на C для распределённых вычислений.
`src` и `include` содержат библиотеку master/worker.
`examples` содержит пример с численным интегралом.
`make` собирает проект через gcc и clang.
`make test` запускает основные тесты и benchmark-и.
`make coverage-test` запускает тесты с покрытием lcov.
`make analyze` запускает статический анализ clang.
`make clean` удаляет файлы сборки и логи.
